# Praktik Plast — Payload CMS + Next.js

Отдельный тестовый проект в ветке `praktik-payload-next`. Исходная ветка `main` и работающий Python-сервис не изменены.

Технические требования: Node 24.22+, Next 16.4, Payload CMS 3.93, PostgreSQL, S3-compatible uploads (required for durable media).

See `docs/SETUP.md` for deployment, initial setup and checks.
